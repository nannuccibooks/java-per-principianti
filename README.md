# Java per principianti

Materiali online per il libro "Java per principianti".

Questo repository raccoglie più progetti completi, numerati in base al codice/esempio a cui fanno riferimento nel libro. Ogni cartella numerata è pensata per essere autonoma: può essere copiata, scaricata o pubblicata come un piccolo repository separato.

## Struttura

| **Risorsa N°** | **Nome**                                                      |
|----------------|---------------------------------------------------------------|
| **1**          | [**Esempi di Operatori Bitwise**]("./001-operatori-bitwise/") |
| **2**          | [**Hello World**]("002-hello-world/")                         |
| **3**          | [**Vacanze**]("003-vacanze/")                                 |
| **4**          | [**Condizione complessa**]("004-condizione-complessa/")       |

## Convenzione per i materiali

Ogni progetto contiene:

- `README.md`: descrizione dell'esempio e istruzioni di compilazione/esecuzione.
- `src/`: codice sorgente Java.
- `.gitignore`: esclusioni utili se il progetto viene usato come repository indipendente.

Per aggiungere un nuovo materiale, creare una nuova cartella top-level con numero progressivo a tre cifre e titolo descrittivo, per esempio:

```text
003-nome-del-progetto/
  README.md
  .gitignore
  src/
```
