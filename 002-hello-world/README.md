# Codice 002: Hello, World!

Il codice permette di vedere un semplice programma "Hello, World!" in Java.

## Struttura

```text
002-hello-world/
  README.md
  .gitignore
  src/
    HelloWorld.java
```

## Compilazione ed esecuzione

Aprire un terminale in questa cartella ed eseguire:

```sh
javac -d out src/HelloWorld.java
java -cp out HelloWorld
```
